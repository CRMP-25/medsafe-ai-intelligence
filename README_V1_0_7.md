# MedSafe V1.0.7-testing

Based on V1.0.6-testing. Association CSV now exports all supporting source IDs and URLs, without the previous `[:8]` cap. New one-click ZIP includes complete investigation JSON, full semantic graph JSON/GraphML, complete associations CSV, evidence records, node and edge CSVs, Markdown and HTML reports, and a manifest. UI graph display controls are unchanged. No persistent server-side storage or clinical causality inference is claimed.
